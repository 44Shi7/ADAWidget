NEVZORA ACCESSIBILITY WIDGET

Install:
1. Upload the complete nevzora-widget folder beside index.html.
2. Upload nevzora-accessibility.js beside index.html.
3. Add this button inside <body>:
   <button id="openWidget" aria-label="Open Accessibility Menu">♿</button>
4. Before </body>, add:
   <script src="nevzora-accessibility.js"></script>

The iframe page is:
nevzora-widget/panel.html

This is an original Nevzora-branded implementation based on the supplied visual reference.
